**Create quickly. Verify seriously. Learn from every run.**

SpQE Lab is an independent French applied-research project, started in August 2025, studying how AI coding models can be placed inside a controlled software-production pipeline.

The objective is not merely to generate code from a prompt. SpQE follows an explicit construction and qualification chain:

**structured SpecBlock → architectural decomposition → module-level tasks → specialized generation agents → qualification harness → diagnosis → targeted repair**

The resulting software can then be evaluated independently through external black-box tests.

## What the current experiments show

Three executable comparisons against Kiro document both strengths and limits.

SpQE produces functional end-to-end Python prototypes and exposes generation failures through executable evidence. The experiments have also demonstrated that localized defects can be diagnosed and repaired without regenerating an entire program.

Independent black-box test batteries are used to evaluate SpQE and Kiro from outside their respective generation pipelines.

The dominant SpQE engineering problem is now concrete: **first-shot contract consistency between generated modules**.

This is a research result, not a hidden caveat. It identifies a measurable boundary between model capability, orchestration, qualification and repair.

## Why model teams may care

SpQE separates several stages that are often hidden inside a single coding-agent interaction:

**specification → decomposition → generation → qualification → diagnosis → repair**

This makes it possible to replace the coding-model backend while keeping the surrounding pipeline and evaluation protocol as stable as possible.

The effect of a model can therefore be studied on:

- first-shot inter-file consistency;
- executable contract compliance;
- inference time and cost;
- qualification outcomes;
- defect localization;
- repair trajectories.

A useful next experiment is therefore direct: connect alternative coding models to the same SpQE pipeline and compare their executable generation, qualification and repair trajectories.
