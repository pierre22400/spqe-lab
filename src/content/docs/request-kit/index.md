The Request Kit provides a lightweight technical contact path for someone who wants SpQE Lab to examine a concrete software specification.

SpQE Lab is not operating an open prototype service or a general submission campaign. However, an engineer, model team or technical organization may send a bounded **SpecBlock** to make the discussion concrete and allow SpQE’s fit, limitations or lack of relevance to be assessed against a real case.

SpQE means **Specification-to-Prototype Qualification Engine** and is pronounced **Speky**.

## Minimal path

1. Read the [complete SpecBlock example](./complete-specblock-example/).
2. Use the [SpecBlock best practices](./specblock-best-practices/) to describe a small, bounded executable target.
3. Add the minimal information requested in the [contact dossier](./contact-dossier-form/).
4. Send the material to `contact.spqe.lab@gmail.com`.

The [prototype request form](./prototype-request-form/) is available when additional framing is useful, but a concise SpecBlock and contact message are sufficient for an initial technical review.

## Scope of the contact

Submitting a SpecBlock does not create a delivery obligation, commercial commitment or guarantee of response. The material may be used only to assess whether a meaningful technical discussion or experiment is possible.

The most useful submissions are small enough to be understood quickly and precise enough to support observable black-box behaviour.
